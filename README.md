## 🚀 Projetos em Destaque

### 🚗 [Análise de Acidentes em Rodovias Federais (PRF, 2025)](https://github.com/ruanzituzs/analise-acidentes-prf)
> **Pipeline completo de Análise Exploratória de Dados (EDA)** sobre uma base aberta de **72.528 ocorrências** da Polícia Rodoviária Federal para mapear fatores determinantes de acidentes graves.
- **Destaques:** Teste empírico de 4 hipóteses (fase do dia, tipo/causa, pista simples vs. dupla, distribuição temporal e geográfica).
- **Resultados Chave:** Evidenciou gravidade 40% maior em pistas simples e alta severidade em colisões frontais e atropelamentos noturnos.
- **Stack:** Python, Pandas, Matplotlib, Seaborn.
- [🔗 Ver repositório com código e gráficos completos →](https://github.com/ruanzituzs/analise-acidentes-prf)

### ⚽ Web Scraping e Análise de Dados Esportivos
